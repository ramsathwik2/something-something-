# Madhu - Taskbar Kitten
No Python needed - just download and double-click.

## For her (no Python)
1. Download `Madhu_Kitty_Gift.zip` from Releases or clone
2. Unzip anywhere (right-click zip -> Properties -> Unblock if SmartScreen shows)
3. Double-click `dist\Kitty\Kitty.exe` (or `Kitty.exe` after unzip)
4. First launch: beautiful card `Meet your kitten` -> type name (default Madhu) -> `That's my name`
5. She appears on taskbar - right-click for menu, tray ^ near clock

If SmartScreen: `More info -> Run anyway` or right-click exe -> Properties -> Unblock

No Python, no install - everything bundled (_internal includes Python 3.12).

## For you (dev)
`run.bat` still works if you have Python, but gift uses `dist\Kitty\Kitty.exe` standalone.

## Features: 150 luck messages, real meow.wav, 11:11 wishes, food always hungry, duck on VS Code/OpenCode, walk everywhere, don't sleep 30m, Our story scrapbook.

Saves to `%APPDATA%\TaskbarKitten\kitten_memory.json` - gift remembers.
